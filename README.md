# R2D Partners — лендинг

Статический сайт партнёрской программы R2D Partners: главная, страница условий (Terms & Conditions) и страница 404. Без сборки и без зависимостей — обычные HTML, CSS и JS.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Лендинг. Стили и скрипты встроены в файл (в т.ч. SVG-логотипы брендов и интерактивная карта рынков). |
| `terms.html` | Terms & Conditions. Тексты на EN, RU и BR, переключаются меню языков в шапке или параметром `?lang=ru` / `?lang=br`. |
| `404.html` | Страница «Page not found» с бегущими лентами. Netlify показывает её на любом несуществующем адресе. |
| `pages.css`, `pages.js` | Общие шапка, мобильное меню, подвал и меню языков для `terms.html` и `404.html`. |
| `_redirects` | Правила Netlify: старые адреса условий (`/terms`, `/ru/terms-ru`, `/br/terms-br` …) ведут на `terms.html` с нужным языком. |
| `serve.js` | Мини-сервер для локального просмотра (не нужен на хостинге). |
| `favicon.ico`, `favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png` | Иконки вкладки и ярлыка на телефоне — взяты с текущего сайта r2d.partners, подключены во все три страницы. |

## Папки

- `img/` — картинки и видео (hero, блоки преимуществ, промо, логотипы отзывов `img/rv/`, флаги `img/flags/`, иконки соцсетей `img/soc/`).
- `data/world.js` — геоданные для карты рынков на главной.

## Локальный просмотр

Нужен Node.js. В корне проекта:

```bash
node serve.js
```

Сайт откроется на http://localhost:5174. Сервер, как и Netlify, отдаёт `404.html` на неизвестные адреса.

> Открывать `index.html` двойным кликом (через `file://`) не стоит: `terms.html` и `404.html` подключают ресурсы по абсолютным путям (`/pages.css`, `/img/...`), им нужен сервер.

## Деплой на Netlify

Сборка не нужна: **Build command** — пусто, **Publish directory** — корень репозитория. Можно подключить репозиторий к Netlify или перетащить папку в Netlify Drop.

## Внешние ресурсы

- Шрифты Unbounded и Montserrat — Google Fonts.
- D3 и TopoJSON для карты — cdnjs.
- Кнопки Login / Sign Up ведут на https://r2d.partners/.

## Что важно знать

- **Тексты условий** перенесены с r2d.partners дословно, включая опечатки оригинала в английской версии («TThe Betting Company…», «commissions. on the Net Revenue»). Править только по согласованию с клиентом.
- **Языки на Terms** повторяют текущий сайт клиента: у RU и BR свои тексты, все остальные языки (PT, ES, FR, IT, DE) показывают английский. На BR-версии вступительные абзацы на английском — так и у клиента.
- **Меню языков на главной** пока только меняет флаг, переводов лендинга нет.
- **Форма контактов** на главной только проверяет поля, показывает «Thanks!» и очищает их — данные никуда не отправляются. Обработчик (Netlify Forms, почта, CRM) нужно подключить.
